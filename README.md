# The Lancer Method — Frontend Website

This is the front-end build for **The Lancer Method** — a personal brand and coaching platform created by Dena Lancer.

The layout is based on a custom Figma design and built using:

- HTML5
- CSS3
- Bootstrap 5
- JavaScript (vanilla)

---

## 🌐 Purpose

This version is a **pixel-perfect static build**, created before migrating to WordPress.  
The goal is to fully match the design and later convert it into a dynamic, editable WordPress theme.
